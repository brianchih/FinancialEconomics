第 4-3 節

經營效率、槓桿與流動性指標

在評估完企業的獲利能力與價值創造（第 4-1、4-2 節）之後，本節進一步探討企業內部的營運效率（Operating Efficiency）、財務槓桿風險（Financial Leverage）與短期償債流動性（Liquidity）。這些指標能協助管理階層與投資人透視公司資產運用的靈活度及面對財務逆境時的安全邊際。

⚙️ 一、 衡量經營效率性 (Operating Efficiency Ratios)

效率性指標衡量企業運用其資產（如總資產、存貨、應收帳款）產生銷貨收入的速度與能力。若資產週轉過慢，代表資金遭到不當積壓，降低整體資金報酬率。

1. 資產週轉率

衡量每塊錢資產能創造多少銷貨收入。

資產週轉率 = 銷貨收入 / 平均資產總額

Home Depot 實例： $83,176 / [(39,946 + 40,518)/2] ＝ 2.07 次 (期初法為 2.05)

2. 存貨週轉率與天數

評估存貨變現速度及滯銷風險。

存貨週轉率 = 銷貨成本 / 年初存貨
存貨天數 = 年初存貨 / (銷貨成本 / 365)

Home Depot 實例： 週轉 4.9 次，平均存貨天數為 74 天。

3. 應收帳款週轉與收帳期間

衡量客戶賒銷付款的回收效率。

應收週轉率 = 銷貨收入 / 年初應收帳款
平均收帳期間 = 年初應收 / (銷貨 / 365)

Home Depot 實例： 週轉 59.5 次，平均收帳期僅 6.1 天。

自我測驗 4.5 思考題

Home Depot 支付帳款的平均天數 (Days Payable)

題目背景：平均收帳期間衡量公司收取帳款的天數。相對地，Home Depot 也會延遲支付自己的帳款（應付帳款）。試利用表 4.1 與表 4.2 資料，求算 Home Depot 支付帳款的平均天數？（提示：計算應付帳款付現天數應以銷貨成本 COGS 為基礎，不包含 SG&A 等間接成本）。

• 應付帳款餘額 (2014年)： $9,473 百萬 (表4.2)

• 每日銷貨成本： $54,222 百萬 / 365天 ＝ $148.55 百萬/天

• 平均支付天數 (Days Payable)： $9,473 / $148.55 ＝ 約 63.8 天

💡 財務意涵：Home Depot 平均 6.1 天向客戶收現，卻能享有約 64 天才支付供應商的寬限期，展現強大的供應鏈議價能力與正向營運資金循環。

⚖️ 二、 衡量財務槓桿與債務風險 (Financial Leverage)

財務槓桿反映企業利用債務融資的程度。適度槓桿能放大股東權益報酬率（ROE），但過高的負債比率與利息負擔會在景氣反轉時帶來嚴重的財務危機。

1. 長期負債比率與總負債比率

  • • 長期負債比率 ＝ 長期負債 / (長期負債 ＋ 股東權益)
      => Home Depot: $16,869 / ($16,869 + $9,322) ＝ 64% (美國製造業平均約 33%)
  • • 長期負債對權益比率 ＝ 長期負債 / 股東權益
      => Home Depot: $16,869 / $9,322 ＝ 1.81 (181%)
  • • 總負債比率 ＝ 負債總額 / 資產總額
      => Home Depot: $30,624 / $39,946 ＝ 77%

2. 利息保障倍數與現金涵蓋比率

  • • 賺得利息倍數 (Times Interest Earned) ＝ EBIT / 利息支付
      => Home Depot: $10,806 / $830 ＝ 13.0 倍
  • • 現金涵蓋比率 (Cash Coverage Ratio) ＝ (EBIT ＋ 折舊) / 利息支付
      => Home Depot: ($10,806 + $1,786) / $830 ＝ 15.2 倍

💡 涵蓋比率加回了非付現的折舊費用，更能真實反映營業現金流支付利息的能力。

自我測驗 4.7

債務重組對槓桿指標的影響

題目：某公司償還 $1,000 萬面值的流通在外負債，並以較低的利率發行 $1,000 萬的新債券，則長期負債比率將會如何？賺得利息倍數比率和現金涵蓋比率會如何？

解答說明：

1. 長期負債比率：由於償還舊債並發行相同金額（$1,000萬）的新債，長期負債總額與股東權益維持不變，因此長期負債比率將保持不變。

2. 利息保障倍數與現金涵蓋比率：由於新債券是以較低的利率發行，利息費用將會減少。在 EBIT（或 EBIT＋折舊）不變的情況下，分母（利息費用）變小，將導致賺得利息倍數與現金涵蓋比率顯著上升（改善）。

💧 三、 衡量短期償債與流動性指標 (Liquidity Ratios)

流動性指標評估企業變現短期資產以償還短期到期債務的能力。對於防範企業陷入技術性破產至關重要。

1. 淨營運資金對資產比率

(流動資產 － 流動負債) / 總資產

Home Depot: 0.10

2. 流動比率 (Current Ratio)

流動資產 / 流動負債

Home Depot: 1.36 倍

3. 速動比率 (Quick Ratio)

(現金+有價證券+應收) / 流動負債

Home Depot: 0.28 倍

4. 現金比率 (Cash Ratio)

(現金+有價證券) / 流動負債

Home Depot: 0.15 倍

自我測驗 4.9

日常交易對流動比率與淨營運資金的動態影響

題目：
a. 某公司擁有 $120 萬流動資產和 $100 萬流動負債。若用 $50 萬現金支付應付帳款，流動比率與淨營運資金會如何？
b. 某公司使用現金支付購買額外存貨，流動比率與速動比率會如何？

(a) 用 $50 萬現金支付應付帳款：

• 交易後流動資產 = $120M － $0.5M = $115M；流動負債 = $100M － $0.5M = $95M。
• 流動比率： 從 $120M/$100M (1.20) 提高至 $115M/$95M (1.21，上升)。
• 淨營運資金： ($120M － $100M = $20M) 變為 ($115M － $95M = $20M)，保持不變（因流動資產與流動負債同額減少）。

(b) 用現金購買額外存貨：

• 這是流動資產內部互換（現金減少、存貨增加），總流動資產與流動負債不變，因此流動比率保持不變。
• 由於速動資產（現金＋應收）減少、存貨被剔除在速動資產之外，速動比率將會下降。
